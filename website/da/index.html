§1

Resumé

Missionsbriefing

Parvaz er en Android-browsertunnel for iranske brugere uden teknisk baggrund, med persisk som standardsprog. En hjælper udruller den oprindelige MasterHttpRelayVPN-Code.gs på sin egen Google-konto. Brugeren får et parvaz://-link over en sikker messenger (Signal eller Telegram, ikke WhatsApp), scanner en QR-kode eller trykker Indsæt, installerer ét MITM-certifikat i Androids indstillinger, trykker Forbind og browser derefter som normalt i Chrome (eller en anden Chromium-browser).

Chromes trafik går gennem Apps Script, med TLS SNI www.google.com og HTTP Host script.google.com. Chrome stoler på Parvaz-CA'en på enheden fra start, uden flag, uden about:config og uden root. Arkitekturen følger den gennemprøvede MasterHttpRelayVPN-RUST-port. Parvaz adskiller sig med den visuelle NOTAM-identitet, en brugerflade der er persisk som standard og en mere målrettet opsætning for passagerer uden teknisk baggrund.

Hvad appen ikke gør · hvad den skal have · grænserne
Gør ikke Nej

  • Intet fælles relay. Hver passager kører sin egen Code.gs.
  • Ingen lokation, kontakter, sms, mikrofon eller kamera (kameraet bruges kun til QR-scanning, og kun hvis du vælger det).

  • Enhedens skærmlås, ellers afviser Android at installere CA'en.
  • En Chromium-browser: Chrome (eller Brave / Edge / Vivaldi). Ingen browserflag nødvendige.

§6

Hvem flyver, og hvem er på jorden

Ærlig afgrænsning
Bemærk Ikke alle sider åbner, og WebSockets understøttes ikke i denne version.
Klar til start Tunnelleres
  • Chrome på Android: ingen flag, ingen about:config, ingen root.
  • Andre Chromium-browsere (Brave, Edge, Vivaldi): samme vej, samme tillid.
  • Hosts ejet af Google (google.com, youtube.com, fonts.googleapis.com) via direkte SNI-omskrivning, i alle browsere.
  • Webapps i Chrome: Gmail, GitHub, Wikipedia, nyhedssider, søgning.
Ingen Apps Script-kvote på Googles hurtige vej. Gennemløb ~5 KB/s · WebSockets virker ikke endnu.
På jorden Tunnelleres ikke
  • Firefox Stable / Beta / Focus: ingen about:config, så tillidsflaget kan ikke sættes.
  • Firefox Nightly: flaget findes, men nulstilles til false ved hver genstart (fenix#18990, åben siden 2021).
  • DuckDuckGo-browseren: bygger på Chromium, men afviser brugerens CA. Bekræftet, at det ikke virker.
  • Native apps: Instagram, Telegram, WhatsApp, bank, streaming. De afviser brugerinstallerede CA'er som standard fra Android 7.
Generel begrænsning for MITM på Android · kombinér med xray + VPS til native apps.

§8

Installér certifikatet · i Indstillinger

Trin 1 af 2 · én gang · ca. 30 sekunder

Tryk på Åbn Indstillinger i Parvaz. Parvaz lægger parvaz-ca.crt i Downloads og åbner Androids indstillinger. Følg derefter stien for din telefon.

proc · cert.001 · samsungOne UI 6 / Android 14
# SAMSUNG (Galaxy): Indstillinger → Sikkerhed og privatliv → Flere sikkerhedsindstillinger → Installér fra enhedslager → CA-certifikat → vælg parvaz-ca.crt i Downloads → indtast din pinkode / dit fingeraftryk → tryk på Installér alligevel i advarslen
proc · cert.001 · pixel / aospAndroid 14 / 15
# PIXEL / almindelig Android: Indstillinger → Sikkerhed og privatliv → Flere indstillinger for sikkerhed og privatliv → Kryptering og loginoplysninger → Installér et certifikat → CA-certifikat → vælg parvaz-ca.crt i Downloads → indtast din pinkode / dit fingeraftryk → tryk på Installér alligevel i advarslen

Forudsætning: skærmlås (pinkode, mønster, adgangskode). Ellers afviser Android installationen. Kan du ikke finde menuen? Søg efter CA-certifikat i Indstillinger. Du kan roligt gå videre trods advarslen. CA'en blev lavet på din telefon, og den private nøgle forlader aldrig appens private lager.

§9

Tryk Forbind · åbn Chrome

Trin 2 af 2 · én gang · ca. 10 sekunder

Tryk på gummistempel-knappen på Parvaz' hovedskærm. Når den skifter til در پرواز (i luften), skal du åbne Chrome og browse som normalt. HTTPS-sider går gennem Parvaz uden yderligere opsætning. Brave, Edge og Vivaldi virker på samme måde. Den Parvaz-CA, du lige har installeret, er det eneste, de behøver.

proc · browser.001 · chromiumengangs · ca. 10 sek.
# 1. Tryk på gummistemplet i Parvaz. → "پرواز" (kontur) skifter til "در پرواز" (fyldt · oliven) # 2. Åbn Chrome (eller Brave / Edge / Vivaldi). → browse bare · ingen flag, ingen about:config, ingen root # 3. (Valgfrit) Tjek ruten: open wikipedia.org # side uden for Google → går gennem MITM open google.com # Google-side → hurtig vej med SNI-omskrivning

Hvorfor Chrome virker: Chrome på Android stoler på brugerinstallerede CA'er fra systemets lager, og Chromes håndhævelse af Certificate Transparency har en udtrykkelig undtagelse for kæder, der udgår fra en brugerinstalleret CA. Derfor bliver Parvaz' leaf-certifikat accepteret uden opsætning. Browsere, der ikke virker, og grænserne for gennemløb og WebSockets står i §6.

Hjælper · udrul relayet

ca. 5 min · én gang · kun for den tekniske hjælper

Er du den tekniske hjælper, der sætter Parvaz op for en anden, er her den engangsudrulning af Apps Script, der skal til. Slutbrugeren åbner aldrig script.google.com.

proc · relay.deploy.001script.google.com · ca. 5 min
# 1. Åbn Apps Script, og opret et nyt projekt open script.google.com # klik på "New project" # 2. Indsæt relay-koden i Code.gs (erstat standardindholdet) view github.com/cocodedk/parvaz/blob/main/apps_script/Code.gs copy → indsæt i fanen Code.gs i editoren # 3. Lav en stærk, tilfældig AUTH_KEY (genbrug ikke adgangskoder) openssl rand -base64 32 # eller en adgangskodemanager · mindst 32 tegn → sæt den ind i Code.gs: var AUTH_KEY = "<indsæt-her>"; → File → Save (Ctrl/Cmd+S) # 4. Udrul som webapp Deploy → New deployment → ⚙ Web app Execute as: Me (din-email@gmail.com) Who has access: Anyone → klik på Deploy → Google beder om OAuth-samtykke første gang → Allow # 5. Find den adresse, der skal ind i Parvaz-appen Apps Script giver dig en webapp-adresse, der ser sådan ud: https://script.google.com/macros/s/AKfycbyLONGRANDOMTOKEN/exec └────────────┬────────────┘ deployment-id # det eneste, du skal bruge Du kan åbne den igen når som helst: Deploy → Manage deployments → kopiér webapp-adressen # 6. Byg parvaz://-adgangslinket ved at sætte de to dele ovenfor sammen parvaz://<deployment-id>/<AUTH_KEY>#<display-name> # konkret eksempel: parvaz://AKfycbyLONGRANDOMTOKEN/7dF9KmY...eY=#رلهٔ‌من # 7. Del KUN via en SIKKER messenger, for dette link indeholder nøglen ✓ Signal · ende-til-ende · anbefalet ✓ Telegram · helst Secret Chat ✗ WhatsApp · cloud-backup, som Meta kan læse → ALDRIG ✗ SMS · kan læses af teleselskabet → ALDRIG ✗ E-mail · kan læses af serveren → ALDRIG

Kvote: ~20k UrlFetch pr. dag · 30 s pr. hentning · 6 min pr. kørsel. Ét relay pr. Google-konto (vilkår for Apps Script). Test det: åbn webapp-adressen i en browser. Du skal se {"e":"unauthorized"}, og det viser, at udrulningen er i live og afviser kald uden godkendelse. Kilde: apps_script/Code.gs · Apps Script · Web Apps.
